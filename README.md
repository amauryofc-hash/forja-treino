# Forja — versão compartilhável

Esta pasta contém somente o aplicativo web compartilhável. Os dados são criados no aparelho de cada pessoa. Não inclui cardápio, carteira, conexão Strava, chaves ou GIFs adquiridos de terceiros.

Ao hospedar no GitHub Pages, configure a fonte como **GitHub Actions**. As conexões Strava e Garmin exigem configuração individual; Garmin/Health Connect é um recurso do APK Android.
